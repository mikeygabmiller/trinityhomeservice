Plan around the trees, not a guess.

Snohomish County’s maintenance guidance ties cleaning to nearby vegetation and debris. Use it as a starting point when discussing repeat maintenance for your property.

Leaf-shedding trees

Plan cleaning after the main late-fall leaf drop. Note whether later debris creates another problem.

Evergreens

Check before the rainy season and after storms that bring down tree debris. Needles may call for a different pattern than one autumn leaf drop.

Gutter guards

Guards and screens still need attention. Tell Louis what is installed so the cleaning scope can be discussed.

Source: Snohomish County: Gutters and Downspouts, maintenance guidance. This is general guidance, not a Trinity service package or a promise that cleaning resolves every drainage issue.

Useful details for a recurring plan

  • When the gutters were last cleaned, if known.
  • How soon leaves or needles built up again.
  • Whether overflow happened during ordinary rain or only a heavy storm.
  • Which corner, run or outlet needs attention.
